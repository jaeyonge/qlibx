# 285 — 성과만 필요하면 포지션 전체를 읽지 않음

## 결론

- 팩터 조합처럼 수익률만 필요한 작업이 전체 전략 보고서를 만들던 낭비를 제거함
- 계좌 전체 중 합계 행과 필요한 열만 저장 파일에서 골라 읽음
- 기존 전체 보고서는 바꾸지 않으며, 새 `strategy_performance`를 선택해서 사용함

## 왜 바꿨는가

- FF3 여섯 포트폴리오의 수익률을 조합하는 단계는 일별 계좌가치만 필요함
- 기존 경로는 종목별 포지션, 체결, 목표 비중, 감시 결과를 모두 읽고 분석했음
- 실제 측정에서 이 보고서 생성이 약 110초였으며, 같은 큰 기록을 일곱 번 읽었음

## 작동 방식

- 저장된 계좌 표를 읽을 때 계좌 합계 행만 고름
- 시간, 현금, 계좌가치처럼 성과 계산에 필요한 열만 읽음
- 이후 수익률·낙폭·샤프지수 계산은 기존 계산기를 그대로 사용함
- 따라서 계산 정의는 같고, 불필요한 입력과 부가 분석만 생략함

## 공개 사용법

```python
from vqapr.public import strategy_performance

performance = strategy_performance(".vqapr", "my-run")
daily_returns = performance.returns
```

포지션 분석이나 체결 분석까지 필요하면 기존 `strategy_report`를 계속 사용함.

## 검증

- 같은 기록에 대해 새 결과와 전체 보고서 안의 성과 결과를 모든 필드에서 비교함
- 24만 종목별 행을 가진 기록에서 기존 2.73초, 개선 0.24초로 측정됨
- 중앙값 기준 약 11.5배 빨라졌으며 결과 해시가 완전히 같음
- 보고서·공개 경계 단위시험 27개, 정적 검사, 타입 검사 통과함
