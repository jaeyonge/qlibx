## 왜 이 변경이 있는가

같은 파일을 쓰는 solver 두 개가 파일 생성 전에 함께 시작할 수 있음. 첫 solver가 자기 규칙의 머리말로
파일을 만든 뒤, 둘째 solver가 파일이 생겼다는 이유만으로 자기 지문을 덧붙이면 서로 다른 floor 규칙의
증명이 한 파일에 섞임. 다음 실행은 그 지문을 잘못 신뢰할 수 있음.

## 무엇이 어떻게 바뀌었는가

- solver가 현재 파일의 버전과 계산 규칙을 직접 확인했는지 별도로 기억함.
- 파일이 늦게 생겼다면 내용을 다시 읽고 같은 규칙임을 확인한 뒤에만 덧붙임.
- 다른 규칙이면 파일을 바꾸지 않고 그 solver의 캐시만 끔.
- 두 solver가 파일 생성 전에 시작하는 순서를 그대로 재현하는 회귀 검사를 추가함.

## 대안과 판단

- 파일 잠금으로 모든 계산을 직렬화하지 않음. 증명 계산 자체를 함께 막을 이유가 없고, 같은 규칙의
  중복 지문은 정답을 바꾸지 않음.
- 다른 규칙의 기존 파일을 덮어쓰지 않음. 사용자가 선택한 파일을 보존하고 새 경로를 고르게 함.
