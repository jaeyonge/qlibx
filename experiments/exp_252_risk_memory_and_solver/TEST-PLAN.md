# 고정 시험 계획

- 실제 준비 자료, 309종목, 하루 64개 위험 상황을 유지함
- 먼저 3개월 실제 자료에서 단순 직접 풀이와 구조 증명을 세 번씩 교차 실행함
- 구조 증명이 5% 이상 느리거나 메모리가 10% 이상 크면 원인을 고치기 전 전체 실행하지 않음
- 다음으로 행렬 생성, 증명, 풀이를 따로 측정함
- 양의 정부호 전용 풀이는 짧은 실제 시험에서 10% 이상 빠를 때만 전체 실행함
- 최종 후보는 전체 기간에서 세 번 실행하고 팩터 파일과 경제적 결과를 비교함
- 전체 시간 100초 이하 또는 현재보다 25% 개선, DataModel 90초 이하, 최대 메모리 700MB
  이하를 합격 기준으로 사용함
- 조건과 기준은 중간에 바꾸지 않음
